# 在别人的机器上装这套桌宠（从零到能听见）

> 这份是给「朋友/同事第一次装」看的。你自己的机器装过就跳过。
> 全程 3 分钟，两条命令 + 重启一次。

---

## 0. 先分清两个包

| 包 | 是什么 | 谁写的 | 装不装 |
|---|---|---|---|
| **`dsh-pet`** | **身体**：形象、动画、气泡、右键菜单、桌面窗口 | PC2005-cloud（npm，MIT） | **必须** |
| **`dsh-pet-voice`** | **嘴 + 耳朵 + 嘀嗒提醒**：念回答、按住说话、到点提醒 | 本仓库 | 想听她说话就装 |

**只装 `dsh-pet-voice` 会怎样**：它启动、探测、日志里写着「没装宠物身体」，然后安静地什么都不做。
屏幕上不会出现鱼，因为身体那个包根本没装。

---

## 1. 装身体

```bash
dsh plugin --profile desktop add dsh-pet
```

> 需要联网（走 npm）。国内网络慢的话配一下 npm 镜像再用。
> 版本要求：**≥ 0.3.8**（本插件的 peerDependency 就是这个范围）。

## 2. 装嘴和耳朵

```bash
dsh plugin --profile desktop add "github:hcr116/hcr116-dsh-pet-voice"
```

## 3. 重开 DSH

两个插件都是宿主插件，**必须重开**才挂得上。
重开后你应该看到：屏幕角落出现一只鱼（默认右上角，`display: desktop` 就是独立浮动窗口）。

## 4. 验一遍（别猜）

> `<端口>` 默认是 **19387**，以 DSH 实际开的为准。

```bash
# ① 身体在不在：能返回 JSON 就是装了
curl http://127.0.0.1:<端口>/dsh-pet-7340/state

# ② 本插件的体检报告
curl http://127.0.0.1:<端口>/dsh-pet-voice/doctor
```

**两个容易踩的坑**（我们自己踩过，写在这儿省你一轮排查）：

- **刚重开的头几秒，身体多半还没挂上路由**（dsh-pet 要拉 Electron 窗口）。插件现在会自己等 3 轮 × 2 秒；`/doctor` 也是每次现探（20 秒内才吃缓存），所以**看到 ❌ 先等 20 秒再查一次**，别急着重装。
- 手动 curl `/state` 时**别单独带 `timeout=`**。dsh-pet 要求 `since` 和 `timeout` 成对出现，只给 `timeout` 会 400 `since and timeout must be used together`——探活就干脆两个都不带。

`/doctor` 会逐条告诉你：

```jsonc
{
  "ok": false,
  "检查项": [
    { "项": "身体（dsh-pet）", "状态": "❌", "怎么修": "dsh plugin --profile desktop add dsh-pet" },
    { "项": "说话",           "状态": "✅", "说明": "sapi" },
    { "项": "耳朵（麦克风）",  "状态": "⛔", "说明": "这台没有语音识别服务" },
    { "项": "嘀嗒提醒",       "状态": "✅", "说明": "已读到凭证" },
    { "项": "配置文件",       "状态": "✅", "说明": "~/.dsh/dsh-pet-voice.json" }
  ]
}
```

`ok:false` 就是有硬伤（一般是身体没装）。`⛔` 表示**这台机器本来就没有**（比如没麦克风），不影响别的。

## 5. 想听到人声（可选）

默认走 Windows 自带的 SAPI（机械音，开箱能用）。想要像人的嗓子：

1. 自己起一个 **GPT-SoVITS** 服务在 `127.0.0.1:9880`
2. 准备一段 5~10 秒的参考音（**自己的声音，别用别人的**）
3. 在 `~/.dsh/dsh-pet-voice.json` 里写：

```jsonc
{
  "speak": {
    "provider": "local",
    "sovits": {
      "url": "http://127.0.0.1:9880",
      "refAudio": "D:/你的声音/ref.wav",
      "promptText": "参考音里说的那句原话，一字不差"
    }
  }
}
```

没起服务也没关系：3 秒连不上会自动退回 SAPI，不会没声。

## 6. 想要嘀嗒提醒（可选）

装的是**滴答清单桌面客户端**并且登录着，本插件会自动从它的本地数据库读凭证，不用你填任何东西。

没装滴答 → 探测不到 → 整个提醒模块静默关闭（不会每小时弹提示）。

## 排错

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 屏幕上没有鱼 | 只装了 `dsh-pet-voice` | `dsh plugin --profile desktop add dsh-pet` 然后重开 |
| 有鱼但不说话 | SoVITS 没起 → 本该退 SAPI 也没声 | 看 `/dsh-pet-voice/doctor` 的「说话」那行 |
| 输入框旁没有「按住说话」 | 这台没有语音识别服务（DSH 语音包没装） | 装语音包，或按提示改用打字 |
| 装完没反应 | 没重开 DSH | 重开 |
| `dsh plugin add` 报权限 | 用的是 deploy key（只绑了一个仓库） | 换成账号级 SSH key，或改用 HTTPS |

## 卸载

```bash
dsh plugin --profile desktop remove dsh-pet-voice
dsh plugin --profile desktop remove dsh-pet
```

配置和日志留在 `~/.dsh/dsh-pet-voice.json`、`~/.dsh/dsh-pet/`、`~/.dsh/dsh-pet-voice.log`，想彻底清就一起删。
