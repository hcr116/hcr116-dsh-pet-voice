# 按住 Ctrl+U 对鱼鱼说话：语音入口并进桌宠的设计

定稿方向是**模式②**：按住 `Ctrl+U` 说话，文字落进你眼前那个会话的输入框，你自己按回车发出去；她照旧用克隆嗓念一句回你。

- 录音在本地转写，模型已在本机，不联网。
- 文字只进你正看着的会话，不会串到后台子代理。
- 这次补齐口播四块：去表情、SAPI 降级、新声掐旧声、只念主会话。
- 只改自写插件 `dsh-pet-voice`，不碰 `dsh-pet` 本体。

## 一次说话，会经过哪几步？ {#flow span=12}

@workflow id=voice-flow title="按住 Ctrl+U 说一句话的完整路径"
| key | 按住 Ctrl+U | external |
| rec | 录音，气泡在听 | frontend |
| stt | 本地转写 | backend |
| busy | 输入框在忙? | backend |
| hold | 暂存，本轮后补写 | backend |
| insert | 插到光标处 | frontend |
| enter | 你按回车 | external |
| answer | 她回答 | backend |
| speak | 挑一句念，掐旧声 | frontend |
| key > rec | 按下 |
| rec > stt | 松手 |
| stt > busy | 出字 |
| busy > hold | 是 |
| busy > insert | 否 |
| hold > insert | 本轮结束 |
| insert > enter | 你改完 |
| enter > answer | 发出 | emphasis |
| answer > speak | 一轮结束 |

## 每一步在干什么？ {#walk span=6}

@steps id=voice-steps
| press | 按住 Ctrl+U | 窗口聚焦时才生效。鱼鱼头顶立刻出现「在听…」。 | voice-flow | key |
| record | 录 16k 单声道 | 采样率按 DSH 转写服务的要求固定，不能改。 | voice-flow | rec |
| text | 本地转写 | SenseVoice 在本机跑，通常一秒内出字。 | voice-flow | stt |
| wait | 输入框在忙 | 她正在生成时输入框锁着。字先存住，本轮结束补写一次。 | voice-flow | busy |
| insert | 插到光标处 | 只插入，不覆盖你已打的字。 | voice-flow | insert |
| send | 你按回车 | 之后就是 DSH 普通的一轮，人格、历史、工具全在。 | voice-flow | enter |
| speak | 挑一句念 | 回完才挑句，避免念到半截话。 | voice-flow | speak |

## 她在念的时候你又开口，会怎样？ {#interrupt span=12}

@sequence id=cut-off title="她念到一半，你按下 Ctrl+U"
| actor you | 你 | external |
| actor page | 网页 | frontend |
| actor host | 插件 | backend |
| actor tts | SoVITS | cloud |
| phase | 她正在念 |
| page | tts | 播放第 3 句 | return |
| phase | 你按下 Ctrl+U |
| you | page | 按住 Ctrl+U |
| page | tts | 掐掉播放 | emphasis |
| page | host | 开始录音 |
| host | page | 气泡：在听… | return |
| page | you | 松手后转写并进输入框 | dashed |

不掐播放的话，麦克风会把她自己的声音录进去，转写结果变成两个人的话。所以按下就静音，和「新声掐旧声」用同一套机制。

## 她念哪一句？ {#pick}

规则固定，不随机。三级优先级：

1. 她回复里有 `口播：……`（也认 `口播词：`、`播报：`）→ 只念这一行。这就是 DSH 准备好的口播。
2. 没有 → 从回复里取第一句能念的话。
3. 整段都念不出来（通篇代码或表格）→ 不念，只留气泡。

兜底按行往下扫，遇到这些都跳过：

| 跳过什么 | 长什么样 |
| --- | --- |
| 代码块 | 三个反引号包起来的那段 |
| 表格行 | 行首是一根竖线 |
| 标题行 | 行首是 `#` |
| 引用行 | 行首是 `>` |
| 路径与命令 | `/usr/local/bin/…`、`dsh plugin add …` |
| 纯英文串 | `SYNTAX-OK`、`node_modules` |

选中以后再清一遍：去掉行内代码、链接、markdown 符号、emoji；在句号问号处收一刀；最多 40 字，超了就在逗号处收尾。

**鱼鱼不念代码**这条写死在规则里，不靠她自觉。

## 出错时怎么走？

| 情况 | 系统行为 | 你看到什么 |
| --- | --- | --- |
| 麦克风没授权 | 不录，不重试 | 气泡：没麦克风权限 |
| `Ctrl+U` 被浏览器吃掉 | 同一动作也绑了 `Ctrl+Shift+U` | 无变化，照样能说 |
| 不在聊天页按下 | 不录 | 气泡：这里没输入框 |
| 她正在生成 | 字先存住，本轮结束补写 | 气泡：等她说完就写进去 |
| 转写为空或太短 | 丢弃，不发送 | 气泡：没听清 |
| 录到 120 秒上限 | 自动停并转写 | 气泡显示转写结果 |
| SoVITS 三秒不通 | 退 Windows SAPI 接着念 | 声音变了，但有心 |
| 念的途中来新的一句 | 掐旧的，只念最新的 | 只听到最后一句 |

## 改了哪些配置？

| 键 | 默认值 | 作用 |
| --- | --- | --- |
| `hotkey` | `Ctrl+U` | 按住说话，另绑 `Ctrl+Shift+U` 兜底 |
| `maxChars` | `40` | 一句最多念多少字 |
| `voice` | `local` | 首选嗓子，失败自动退 `sapi` |
| `sovits.url` | `http://127.0.0.1:9880` | 克隆嗓服务 |
| `sovits.timeoutMs` | `3000` | 超过就判失败，退 SAPI |
| `sapi.voice` | 系统默认 | 降级时用的声音 |
| `mainSessionOnly` | `true` | 只念你眼前那个会话 |
| `bubbleMs` | `9000` | 气泡停留时长 |

配置在 `C:\Users\Administrator\.dsh\dsh-pet-voice.json`，每次说话时现读，改完不用重启。

## 这一版不做的

@callout level=note title="都不做，别以为是漏了"
- 失焦自动停录音：你说了先不做，切窗口时录音会继续。
- 八秒没答说「还在想」：她答得不慢，做了反而插废话。
- 念子代理会话：已经关掉。
- 原生耳朵：网页热键在别的软件里按不到，那是另一套方案。
