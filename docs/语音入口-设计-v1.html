按住 Ctrl+U 对鱼鱼说话：语音入口并进桌宠的设计

长图

答

结论

定稿方向是模式②：按住 Ctrl+U 说话，文字落进你眼前那个会话的输入框，你自己按回车发出去；她照旧用克隆嗓念一句回你。

  1. 录音在本地转写，模型已在本机，不联网。
  2. 文字只进你正看着的会话，不会串到后台子代理。
  3. 这次补齐口播四块：去表情、SAPI 降级、新声掐旧声、只念主会话。
  4. 只改自写插件 dsh-pet-voice，不碰 dsh-pet 本体。

适用于DSH 0.2.1-rc.2Windows本机 127.0.0.1不做失焦自动停

2

每一步在干什么？

  1. 按住 Ctrl+U ↗

    窗口聚焦时才生效。鱼鱼头顶立刻出现「在听…」。

  2. 录 16k 单声道 ↗

    采样率按 DSH 转写服务的要求固定，不能改。

  3. 本地转写 ↗

    SenseVoice 在本机跑，通常一秒内出字。

  4. 输入框在忙 ↗

    她正在生成时输入框锁着。字先存住，本轮结束补写一次。

  5. 插到光标处 ↗

    只插入，不覆盖你已打的字。

  6. 你按回车 ↗

    之后就是 DSH 普通的一轮，人格、历史、工具全在。

  7. 挑一句念 ↗

    回完才挑句，避免念到半截话。

3

她在念的时候你又开口，会怎样？

图的结构
  • 你 you
  • 网页 page
  • 插件 host
  • SoVITS tts
  • page → tts · 播放第 3 句
  • you → page · 按住 Ctrl+U
  • page → tts · 掐掉播放
  • page → host · 开始录音
  • host → page · 气泡：在听…
  • page → you · 松手后转写并进输入框

不掐播放的话，麦克风会把她自己的声音录进去，转写结果变成两个人的话。所以按下就静音，和「新声掐旧声」用同一套机制。

4

她念哪一句？

规则固定，不随机。三级优先级：

  1. 她回复里有 口播：……（也认 口播词：、播报：）→ 只念这一行。这就是 DSH 准备好的口播。
  2. 没有 → 从回复里取第一句能念的话。
  3. 整段都念不出来（通篇代码或表格）→ 不念，只留气泡。

口播其余三块，补什么？

这块设计老桌宠的做法现在这一版
去表情去掉 emoji 与代理对再送 TTS会卡只去了 markdown，emoji 还在补上
降级链local 打不通当场退 SAPI没声只有 local，SoVITS 没起就静默补上，3 秒判定
掐旧声新的直接掐掉上一条会插错排队串行，上一条念完才轮到改成只留最新
念哪些会话全部刷视频那轮会念摘要连子代理会话也念只念主会话
6

老桌宠还有哪些没接进来？

老功能老桌宠怎么做现在在不在本鲸的看法
转述 QQ 里她说的话一条 ssh 长连接 tail -F 服务器的 outbox.jsonl断了旧版本功能，现在未接入接法清楚，留着以后接
到点提醒reminders.json + 托盘通知断了旧版本功能，现在未接入可接，改成气泡加念
在 QQ 里说「提醒我 9 点喝水」服务器插件写 {"type":"reminder"} 顺着 ssh 下来靠上一条旧版本功能，现在未接入接完提醒才有意义
拖动、缩放、记位置窗口拖动，滚轮 0.6 到 1.9没核位置和大小有，滚轮缩放没对过不用接
托盘与右键菜单自己画两套，还不一致有dsh-pet 有自己的右键菜单用它的
开机自启、单实例启动文件夹快捷方式有跟 DSH 一起起不用接
三条嗓子local、azure、sapi只有 local这版补 sapi
八秒没答说「还在想」有没做不做
长回答分段念计划过，没实装没做不做

QQ 那两条：记下来，这一版不接

这三条是旧版本（C# 桌宠）的功能，现在未接入。接法清楚：插件里加一条定时任务，走同一条 ssh 拉 outbox.jsonl，新行就冒气泡并念出来。跟这次改动不冲突，但算另一件事，先记着。

7

出错时怎么走？

情况系统行为你看到什么
麦克风没授权不录，不重试气泡：没麦克风权限
Ctrl+U 被浏览器吃掉同一动作也绑了 Ctrl+Shift+U无变化，照样能说
不在聊天页按下不录气泡：这里没输入框
她正在生成字先存住，本轮结束补写气泡：等她说完就写进去
转写为空或太短丢弃，不发送气泡：没听清
录到 120 秒上限自动停并转写气泡显示转写结果
SoVITS 三秒不通退 Windows SAPI 接着念声音变了，但有心
念的途中来新的一句掐旧的，只念最新的只听到最后一句

改了哪些配置？

键默认值作用
hotkeyCtrl+U按住说话，另绑 Ctrl+Shift+U 兜底
maxChars40一句最多念多少字
voicelocal首选嗓子，失败自动退 sapi
sovits.urlhttp://127.0.0.1:9880克隆嗓服务
sovits.timeoutMs3000超过就判失败，退 SAPI
sapi.voice系统默认降级时用的声音
mainSessionOnlytrue只念你眼前那个会话
bubbleMs9000气泡停留时长

配置在 C:\Users\Administrator\.dsh\dsh-pet-voice.json，每次说话时现读，改完不用重启。

9

这一版不做的

都不做，别以为是漏了

- 失焦自动停录音：你说了先不做，切窗口时录音会继续。 - 八秒没答说「还在想」：她答得不慢，做了反而插废话。 - 念子代理会话：已经关掉。 - 原生耳朵：网页热键在别的软件里按不到，那是另一套方案。

后面想做的（这一版不做）

想做的事现在是什么样打算怎么做
动作跟状态匹配随机链按权重抽：待机 10%、转向 5%、移动 5%、小动作类 80%（类里再按权重抽，eg 20/20/16/14/10），抽到什么播什么，跟她在干什么没关系关掉随机链（fixedEnabled），改成状态驱动：她在跑工具就播忙、等你回话就原地等、被戳就生气、闲久了打盹，走 /anim?pet=&lock= 点播，不用 fork dsh-pet
接嘀嗒清单完全没有拉嘀嗒的待办与提醒，到点冒气泡、开口念；跟「到点提醒」共用一条调度
提醒（本地）老桌宠有，现在未接入跟嘀嗒那条合并做，不再自己存 reminders.json

为什么这次不做

这三件事都要新增后台循环或外部接口，跟「按住说话」不是一条链路。先把语音闭环跑稳，再动它们。
